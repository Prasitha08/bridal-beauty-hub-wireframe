BRIDAL BEAUTY HUB — WIREFRAMING SUBMISSION

FILES
1. index.html
   Open this file in Chrome, Edge or Firefox. It is a responsive clickable
   low-fidelity prototype. Use the top tabs or the buttons inside the phone.

2. Bridal_Beauty_Hub_Wireframing_Assignment.pdf
   Includes project overview, research assumptions, sample persona, user flow,
   design thinking process, seven wireframe sketches and a usability test plan.

PUBLISH AS A PUBLIC SUBMISSION LINK (GitHub Pages)
1. Sign in to https://github.com/
2. Create a new PUBLIC repository named bridal-beauty-hub-wireframe
3. Upload index.html and the PDF to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. Your URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/bridal-beauty-hub-wireframe/
8. Open the URL in a private/incognito window to verify it works, then submit it.

NOTE
This package is ready for review, but it has not been uploaded to your personal
GitHub or Google Drive. A public URL is created only after you publish it.
The persona and research points are clearly marked as sample assumptions;
replace them with real user feedback if your assignment requires actual research.
